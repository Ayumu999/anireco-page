⚠ この説明書の前提について（先にお読みください）

この説明書は動物園での運用を想定した表記に書き換えたものです。 現在のプログラムは、決まった順に流れる動物の映像クリップに合わせて動く作りになっています。 そのため、以下の2点は説明書の書き方と、画面に実際に出る文字が一致しません。

  • 第2部 3-2 の「展示場の選択」は、画面上では ［このクリップの頭で同期］ というボタン名のままです。
  • 診断表示の 同期: clip01 T+12.4s や キャッシュ: 5クリップ / 20解説 も「クリップ」という言葉のまま表示されます。

画面に出ているボタン名・文字は、この説明書の中でも［　］で囲って原文のまま残してあります。探すときはそちらを見てください。

PART 1

来園者向け

かぶる → 動物を枠に入れる → 右手の指のボタンを1回引く。それだけです。

1これは何ができるの?

目の前の展示場に動物がいます。「今の動き、なんだろう?」と思った瞬間にボタンを引くと、AIが引いた瞬間からさかのぼって10秒間の動きを見て、何をしていたのかを解説してくれます。

あわせて、その動物についての3択クイズが1問出ます。

2使うボタンは2つだけ

色が付いているところが、使うボタンです。

左手のトリガークイズの選択肢を選ぶときだけ（ポインターで指す）
右手のトリガーアニレコ！（問いかけ）。使うのは基本これだけ
⚠ クイズは必ず左手で選んでください。 右手のトリガーは「問いかけ専用」なので、右手で選ぼうとすると、選ばずに次の問いかけが始まってしまいます。

3使いかた（3ステップ）

STEP 01

枠に入れる

半透明の横長の枠が浮かんでいます。この枠の中がAIの見る範囲です。顔を動かして、展示場の動物を枠の中に入れてください。枠は顔の向きについてきます。

STEP 02

引く

面白い動きが来たら右手のトリガーを1回引く。掛け声が鳴って解析が始まります。枠の上に「アニレコ中...」と出るので、そのまま数秒待ちます。

STEP 03

読む

枠の上に解説、枠の下にクイズが出ます。答えたい人は左手のポインターで1つ選んでください。真ん中は透けているので動物は見えたままです。

読み終わったら、また面白い動きが来たときに右手のトリガーを引いてください。何度でも引けます（1〜2分で2〜3回が目安）。

待ち時間体感
〜5秒押してすぐ出ます。いちばん多い状態です
5〜8秒ひと呼吸ぶん。動物を見ているうちに出ます
8〜15秒少し待ちます。くわしく調べる設定のときや、園内の電波が弱いときです

待っているあいだ、枠の上に「アニレコ中...」と出ます。時間がかかっても必ず何かが出ますので、そのままお待ちください。

4画面の見かた

見えるもの意味
半透明の横長の枠AIが見る範囲。動物をこの中に入れる
枠の内側・下辺の文字操作の案内（「アニレコ：右コントローラのトリガーボタン」）。解析中は暗くなります
枠の上解説
枠の下3択クイズ（出ないこともあります）

5うまくいくコツ

始まってすぐ引く

面白い動きが始まってすぐに引いてください。見終わってから引くと、その動きが対象の10秒から外れてしまいます。

枠に大きく入れる

枠の外の動物・背景・まわりの人は、AIは見ていません。動物を枠の中に大きく入れてください。

解析中は待つ

案内の文字が暗くなっている間は反応しません。焦らずそのままお待ちください。

6こんな表示が出たら

表示意味どうする
判定しきれません。もう一度、動物を枠に入れて試してください。AIが判断しきれなかった回です動物を枠に入れ直して、もう一度引くだけでOK
クイズが出ないクイズが付かない回もあります（異常ではありません）そのまま次の問いかけへ
解説の漢字がひらがなになっているお子さま向けの表示になっていますそのままお楽しみください
「カメラが使えません」という案内一部の機能が止まっています。体験は続けられますスタッフにお声がけください
解説の下に見慣れない英数字の1行調整用の表示が残っていますスタッフにお声がけください

7しなくていいこと

消す操作

解説とクイズは、出てから約60秒で音とともに自動で消え、最初の画面に戻ります。

途中でやめる操作

ありません。引いたあとは必ず解説まで進みます。

気をつかうこと

ヘッドセットはいつ外してもかまいません。壊れませんし、かぶり直せば続けられます。

8困ったら

うまく動かない・見えない・気持ち悪い — どれもすぐスタッフにお声がけください。

無理をせず、いつでも外してかまいません。

PART 2 ／ STAFF ONLY

動物園スタッフ向け

対象読者：動物園スタッフ（非エンジニア）。来園者には案内しません。
この部の役割：スタッフパネルの見かたと、切り替えられるもの全部の一覧、応答速度の早見表（6）。 1日の業務の流れは docs/business/WorkflowGuide.md、画面ごとの詳細は docs/business/ScreenGuide.md、 開園日までに開発者が処理する項目は ExhibitionChecklist.md が正です。

⚠ 先に読む3つ（ここを知らないと「壊れている」と誤解します）

  1. どの切り替えも「押した瞬間」ではなく「次の問いかけから」効きます。 表示中の解説・クイズは変わりません。→ 切り替えたら、もう一度問いかけてもらってから確認してください。
  2. アプリを起動し直すと、切り替えは全部初期値に戻ります。（モード=高速 / モデル=lite / クイズ表示=出す / キッズモード=しない / 待ち上限=30秒 / 展示場の選択=未設定）。毎朝・機材交代のたびに設定し直しが必要です。
  3. 「APIキー: 設定済み」は、鍵のファイルがあることしか見ていません。 実際にAIにつながるかは、試しに1回問いかけて「直近経路: ライブ」を見るのが唯一の確認です。
⚠ 実機での通し確認はまだ済んでいません。 本文の内容は「実際にそう作られている」ことは確認済みですが、ヘッドセットでの見え方・押しやすさは未確認です。違和感があれば遠慮なく開発者へ報告してください。

1スタッフパネルの開き方・閉じ方

色が付いている2つのボタンを、同時に押し続けます。

左手コントローラの X ＋ Y を、同時に2秒押し続ける片方だけ・短押しでは開きません。もう一度同じ操作、または［閉じる］で閉じます
開く左手コントローラの X と Y を、同時に2秒押し続ける（片方だけ・短押しでは開きません）
操作する左手のポインター（光線）でボタンを押す
閉じる一番下の ［閉じる］、または開くときと同じ X＋Y 2秒
  • 開くと目の前（約1.2m）に出て、顔の向きについてきます。
  • 開いている間も体験は止まりません（来園者は問いかけできます）。
  • 来園者には案内しません。 通常の操作では絶対に開きません。
  • パネルは時間では閉じません（解説の自動消灯とは無関係）。

3切り替えられるもの — 全部の一覧

共通ルール：すべて「次の問いかけから」反映 ／ 再起動で初期値に戻る（保存されません）。

3-1. モード（上段の4ボタン） 初期値 = 高速

AIに何コマ見せるかを決めます。左から軽い順です。

ボタンAIに見せるコマ数音声使いどころ
超高速10コマなし回線が弱いときの逃げ場。時間切れが起きたときの自動の落ち先でもある
高速 初期値20コマなし標準の運用値。 迷ったらこれ
標準50コマなし回線が良く、読み取りの精度を上げたいとき
詳細100コマありいちばん重い。時間がかかります
  • 画像の大きさ・画質はどのモードも同じです（変わるのはコマ数と音声の有無）。
  • 今どれが選ばれているかは、①ボタンの色 ②「モード: 高速」の行の2か所で分かります。
  • ⚠ 軽くすれば必ず速くなるわけではありません。 園内の電波の揺れのほうが支配的で、超高速でも遅いことがあります（故障ではありません）。屋外の展示場では特に起きやすいと考えてください。
  • ⚠ 超高速はコマが半分になるので、行動の読み取りが外れやすくなる可能性があります。

自動で軽くなる仕組み（降格）

  • 待ち上限の時間切れが1回起きると、自動で「超高速」に固定されます。 診断行に 降格中 → 実効 超高速 と出ます。
  • 戻りかたは2つ：①ライブの解説が1回成功したら、選んでいたモードに自動で戻る ②スタッフが手でモードを押し直すと解除される。
  • ⚠ すぐ超高速に落ちすぎると感じたら、そう報告してください。

3-2. 展示場の枠（1〜5）＋［このクリップの頭で同期］

いま来園者がどの展示場の前にいるかをアプリに教える操作です。電波が届かず用意済み解説に切り替わったとき、どの動物の解説を出すかがこれで決まります（設定していないと、その展示場用ではない当たりさわりのない文言になります）。

⚠ ボタン名は画面上では［このクリップの頭で同期］のままです。 「クリップ」は映像版の呼び名で、動物園では「この展示場に決める」という意味になります（冒頭の前提を参照）。
手順  ①いる展示場の番号の枠を押す  →  ②［このクリップの頭で同期］を押す  →  ③読み出しがその展示場の表示に変わる
  • 展示場を移動したら、そのつど押し直します。 移動しない設置なら、朝に1回だけで済みます。
  • ⚠ この設定は覚えません。 起動のたび・機材交代のたびにやり直してください。
  • ⚠ 動物園では用意済み解説の当たりが弱くなります。 映像版は「決まった映像の、決まった時間帯」に解説を紐づけていましたが、本物の動物は何をするか決まっていません。電波が落ちた回はその動物の一般的な解説になります。

3-3. ［モデル切替］ 初期値 = gemini-3.5-flash-lite

AIの種類を順ぐりに切り替えます（押すたびに巡回）。

gemini-3.5-flash-lite（初期値・軽くて速い）
  → gemini-3.5-flash
  → gemini-3.6-flash（高性能・遅い）
  → 最初に戻る
  • 今どれかは診断行の モデル: … で分かります。
  • 使いどころ：①解説の質を上げたいとき ②利用制限（429）に当たったときの逃げ道。制限はAIの種類ごとに効くので、切り替えると通ることがあります。
⚠ 上位のAI（gemini-3.6-flash）は実測で約12秒かかります。 切り替えたら待ち上限もセットで長くしてください（→ 3-6）。そうしないと「判定しきれません」しか出なくなります。

3-4. ［クイズ表示］ 初期値 = 出す（On）

見分けかた①ボタンの色（出す=オレンジ / 出さない=くすんだ色） ②「クイズ表示: On」の行
出さないとクイズを作ること自体をやめるので、待ち時間とAIの利用量が減ります。解説だけが枠の上に出ます（解説の位置・大きさは変わりません）
使いどころ行列ができて回転を上げたいとき / 大人だけのとき / 時間がないとき
「出さない」にしているのにクイズが出たら、不具合の合図です（回線が落ちた回もクイズは出ない作りです）。開発者へ連絡してください。

3-5. ［キッズモード］ 初期値 = しない（Off）

解説とクイズをひらがな・カタカナ・数字だけの表記にします。

見分けかた①ボタンの色 ②「キッズモード: Off」の行
かなになるその場でAIが作る解説と3択クイズだけ（問題文・選択肢・正解の一言も含む）
かなにならない操作の案内・「解析中」などの決まった文言・このパネル自体・用意済み解説（回線が落ちた回）
使いどころ小さいお子さま連れのとき。付き添いの方に「お子さんが自分で読めるようにできます」と声をかけられます
  • ⚠ AIが守らずに漢字が混ざることがあります。混ざってもそのまま表示します（故障ではありません）。 これは「AIへのお願い」であって強制ではないためです。
  • あまりに読みにくい場合はモデル切替で上位のAIにすると改善することがあります（応答は遅くなります）。
  • ⚠ お願いの文言そのものは、当日その場では変えられません（アプリの作り直しが必要）。気づいたことは記録して開発者へ。

3-6. ［待ち上限］ 初期値 = 30秒

押してから結果が出るまで待つ時間の上限です。押すたびに巡回します。

15秒  →  30秒（初期値）  →  45秒  →  60秒  →  15秒 …
  • 上限を過ぎると待つのをやめて、用意済み解説に切り替わります。
  • この上限はモードでもAIの種類でも変わりません（全部共通のひとつの値です）。
  • 今何秒かは診断行の モデル: … / 待ち上限 30秒 で確認します（色では示されません）。
  • ⚠ 回線が完全に切れている場合は、上限を待たずに約3秒で切り替わります。 長く待つのは「送信は終わったがAIが考え込んでいる」場合だけです。
値位置づけ
15秒園内運用では使わない値。 上限がちゃんと効いているかを確かめるためのもの
30秒初期値。標準の運用値
45 / 60秒上位のAIに切り替えた日 / 詳細モードを使う日 / 電波の弱い展示場で上げる
⚠ 長くすると、失敗したときに来園者がそのぶん立ち尽くします（60秒にすれば60秒）。⚠ どの値も「実際に何秒かかるのかを測るための暫定値」です。 実測後に運用の値へ決め直す作業が ExhibitionChecklist.md 2-18 / 2-20 に登録されています。

3-7. ［閉じる］

パネルを消すだけです。設定・状態は何も変わりません。

4診断表示の読みかた（小さい5行）

表示見かた
APIキー: 設定済み(ライブAI有効)鍵のファイルがあるだけ。⚠ つながるかは見ていません（拒否されていても「設定済み」と出ます）

「直近経路」の意味

  • ライブ ＝ AIが答えた（正常）
  • キャッシュ(行動一致) ＝ 用意済み解説。回線か時間切れ。同期が合っていれば内容は妥当
  • 汎用 ＝ 用意済み解説の中でも当たりが無かったとき。同期がずれている可能性

⚠ 「汎用」が続いたら

ライブAIが機能していない合図です（回線 / 利用制限 / 鍵のどれか）。まず［モデル切替］を1回押して、次の問いかけを見てください。

［待ち上限］はいくつにするか

7トラブル早見表

症状アプリが自動でやることスタッフの対処
電波が遅い・切れた自動で用意済み解説に切替（来園者には見た目の区別なし）。時間切れ1回で超高速へ降格基本は何もしなくてよい。 長引くなら手動で超高速、または予備回線（テザリング）へ
上位AIにしたら「判定しきれません」ばかり上限を過ぎて用意済み解説へ［待ち上限］を45〜60秒に上げてもう一度。それでも駄目ならモデルを軽く戻す
切り替えたのに変わらない—正常です。 次の問いかけから効きます。もう一度問いかけてもらってから確認
「直近経路: 汎用」ばかり続く—ライブAIが機能していない。［モデル切替］を1回押して次を見る。駄目なら開発者へ
キッズモードなのに漢字が混ざる—仕様どおり。 記録して開発者へ。上位AIに切り替えると改善することも
「クイズ出さない」なのにクイズが出た—不具合の合図。開発者へ連絡
「カメラが使えません」の案内ライブ解説だけ無効。体験は用意済み解説で継続来園者の合間に「設定 → アプリ → このアプリ → 権限」でカメラ許可をやり直し、アプリを起動し直す
解説の下に見慣れない英数字の1行—調整用の表示が残っている。開発者に連絡して消してもらう（体験は続けられる）
解説が「今の行動」より前を指している解説が見るのは引く直前の10秒来園者に「面白い動きが始まってすぐに引いて」と案内。続くなら開発者へ
動物が寝ている・遠い・ガラスで反射する—動物園ならではの状況です。 枠に大きく入るところまで近づいてもらう。動きが無い時間帯はクイズだけでも成立するので「クイズ表示=出す」のままに
来園者が外した / かぶり直した進行中の解析は破棄され、待機画面に戻るそのまま続行してよい
解説が出たまま来園者が離れた約60秒で自動的に消えて待機画面に戻る（音が鳴ります）対応不要
電池切れ・発熱—予備機に交代 → 交代後は第2部 8 の開園前手順をやり直す（展示場の設定も切り替えも忘れるため）
この体験は「絶対に止まらない」設計です。 電波が死んでも自動で用意済み解説に切り替わって続くので、多くの場面でスタッフの操作は不要です。

8開園前・閉園時（要点）

手順の正は docs/business/WorkflowGuide.md §3.1 / §3.4 です。ここは要点だけ。

開園前

  1. 充電・予備機・衛生カバーの確認
  2. その日に使う展示場を決める（枠1〜5のどれに当てるかをスタッフ間で共有）
  3. アプリ起動 → カメラとマイクの許可を両方「許可」（2回目以降は出ません）
  4. パネルを開く（左 X＋Y 2秒）→「APIキー」「カメラ」「キャッシュ件数」を確認
  5. 展示場の前で電波チェック → 弱ければモードを高速 or 超高速に
  6. 展示場の設定（枠を選んで［このクリップの頭で同期］）
  7. 試しに1回問いかけ → 解説が出て、「直近経路: ライブ」になることを確認
  8. 初期状態の目視確認：モード=高速 / クイズ表示=On / キッズモード=Off / 待ち上限=30秒
    ⚠ ここは人の目でしか確かめられません。違っていたら開発者へ
  9. 解説の下に技術的な1行が出ていないことを確認

閉園時

  1. アプリ終了、本体・コントローラ・予備機を充電
  2. 振り返り用の記録の回収（文字のみ。映像・音・鍵は含まれません）
    /sdcard/Android/data/com.ayumu999.anireco/files/logs/anireco_run.log
    取り出しはエンジニアに依頼可
  3. 翌日も出すなら開園前手順を最初からやり直す（設定は何も残りません）

9その場では変えられないもの

以下はアプリの作り直し（再ビルド）や設定ファイルの変更が必要です。当日は「記録して伝える」までが仕事です。

  • 解説が見る長さ（現在10秒）
  • 解説が自動で消えるまでの時間（現在約60秒）
  • キッズモードのお願いの文言
  • AIへのプロンプト本文
  • 調整用の技術表示のOn/Off（現在はOff）
  • 効果音の差し替え
    音源の入れ替えのみ。プログラム変更は不要
  • フォーカス枠の大きさ・位置
